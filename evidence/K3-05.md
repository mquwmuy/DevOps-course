
# K3-05 — Разбор лога pipeline

## Воспроизведение ошибки

В файле .github/workflows/student-ci.yml
путь к Dockerfile был временно изменён
с lab/Dockerfile на lab/MissingDockerfile.

Событие: push
SHA: d7fd18355cb253707b7be157ff576e633fa972a8

Ссылка на неуспешный запуск:
https://github.com/mquwmuy/DevOps-course/actions/runs/43493617742

Результат:

- test: success
- build: failure

## Ошибка из лога

ERROR: failed to build: failed to solve: failed to read dockerfile: open MissingDockerfile: no such file or directory

Process completed with exit code 1.

## Причина ошибки

Docker не смог найти файл MissingDockerfile,
поскольку такого файла нет в репозитории.

Тесты приложения прошли успешно, однако сборка
завершилась ошибкой из-за неправильного пути.

## Исправление

В workflow восстановлена правильная команда:

docker build -f lab/Dockerfile -t devops-student:${{ github.sha }} lab

Событие: push
SHA: 958a88164c76f2ceb388659a178493ff907ff892

Ссылка на исправленный запуск:
https://github.com/mquwmuy/DevOps-course/actions/runs/43494110446

Результат:

- test: success
- build: success

## Вывод

Анализ логов помогает определить причину сбоя
и понять, на каком этапе возникла ошибка.

Ошибка тестирования означает, что результат
приложения не соответствует ожидаемому.
Ошибка отсутствующего Dockerfile связана
с конфигурацией сборки.

После восстановления правильного пути
pipeline успешно выполняет тесты и сборку.
