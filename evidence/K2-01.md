# K2-01. Образы и контейнеры

## Проверка образа
Выполнила команду `docker image inspect devops-course:base`

Образ существует. Он используется сервисами `api` и `web`. Приложение запускается командой `python app.py`, порт 8000

## Проверка контейнеров
Команда `docker compose ps` показала два контейнера:
- `api` - принимает и хранит заявки
- `web` - обслуживает веб-страницу и передаёт запросы сервису `api`

Оба контейнера имеют статус `healthy`

## Остановка и запуск web
Выполнена команда `docker compose stop web`. Контейнер `web` остановился, сайт стал недоступен, а `api` продолжил работать

Затем выполнена команда `docker compose start web`. Сайт снова стал доступен, оба контейнера вернулись в состояние `healthy`

## Вывод
Сервисы `web` и `api` работают в отдельных контейнерах на основе одного образа. Остановка `web` не останавливает `api`, а повторный запуск `web` восстанавливает доступ к сайту
