КТ2-03. Compose и сохранность данных



1\. Настройка Compose



Создан файл `compose.student.yaml` на основе `compose.yaml`

Для сервисов `api` и `web` указан образ `devops-student:v1`. Остальные настройки сохранены



Проверка конфигурации:



```powershell

docker compose -f compose.student.yaml config

```



Результат: конфигурация прочитана без ошибок



2\. Запуск приложения



```powershell

docker compose stop

docker compose -f compose.student.yaml up -d

docker compose -f compose.student.yaml ps

```



Результат: сервисы `api` и `web` запущены. Оба сервиса имеют статус `healthy`



3\. Проверка сохранности данных



До пересоздания API в приложении было 3 заявки



Команда пересоздания:



```powershell

docker compose -f compose.student.yaml up -d --no-deps --force-recreate api

```



После пересоздания `api` снова перешёл в состояние `healthy`



Наблюдение: заявки №1, №2 и №3 сохранились. Затем успешно создана заявка №4 «Не запускается программа». Всего отображается 4 заявки.



Вывод: данные сохранились благодаря тому, что каталог `/data` подключён к отдельному тому `requests`

4\. Назначение настроек



\- `API\_URL: http://api:8000` - адрес API, доступный веб-сервису внутри сети Compose

\- `8000` - внутренний порт приложения. Веб-сервис обращается к API через имя сервиса `api`

\- `127.0.0.1:8080:8000` -порт `8080` компьютера связан с портом `8000` контейнера `web`

\- `requests:/data` - подключает том для хранения заявок вне файловой системы контейнера



Том нужен, чтобы данные не пропадали при пересоздании контейнера



5\. Инструкция запуска



Из корневой папки проекта выполнить:



```powershell

docker compose -f compose.student.yaml config

docker compose -f compose.student.yaml up -d

docker compose -f compose.student.yaml ps

```



Приложение доступно по адресу http://localhost:8080.
